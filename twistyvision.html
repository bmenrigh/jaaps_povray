Credits

TwistyVision is based on Twisty Renderer, which itself is based on Jaap Scherphuis’s Sphere Symmetry Applet. The Twisty Renderer POV-Ray code used for rendering was originally written by Stef-n. Much of the analysis determining which polyhedra to include was done by Matt Galla. Many of the polyhedra would not have been practical to implement without David McCooey’s Visual Polyhedra site.

TwistyVision is a modern remake that performs ray marching directly in WebGL, providing an immediate interactive preview in the browser.

Bugs, inquiries, and complaints should be directed to Brandon at twisty_renderer-＠-brandonenright.net.
